AI analysis (optional)

Connect Claude to act as an expert Bayesian + historical-critical scholar. When connected, Recalculate sends your uploaded sources and the criteria to Claude, which proposes the likelihoods with reasoning and verbatim quotes. Every quote is checked against your sources — anything not found literally is flagged and discarded. You can still edit every number afterward.

Your API key is stored only in this browser (localStorage) and sent directly to Anthropic. It is never placed in the site's code or shared. Each Recalculate is a billed API call on your Anthropic account. Leave the key blank to keep the tool fully offline and deterministic.
